# ClaudeBar v0.3.4

**Rediseño "tipo Apple" completo.** Desde tu última versión (0.2.0) ClaudeBar ha cambiado de arriba
a abajo: un lenguaje visual coherente, señales que se leen de un vistazo, una mascota que reacciona a
tus sesiones de Claude Code y, ahora, **microinteracciones fluidas** en todo el panel.

### ✨ Microinteracciones (lo nuevo de esta versión)
- El panel **aparece con un fade** y las secciones **entran escalonadas**.
- Los **números y las barras deslizan** suavemente hasta su valor (en vez de saltar).
- Las **filas se resaltan al pasar el ratón** y la mascota **parpadea, gira un spinner y suelta un verbo
  con guiño** mientras trabaja.
- Cuando se **renueva la cuota**, un pequeño **destello de celebración**.
- Todo respeta un interruptor **"Reducir movimiento"** (Ajustes) si prefieres cero animación.

### 🐱 Sesiones en vivo + mascota
- Una **mascota ASCII** en el dashboard reacciona en tiempo real a tus sesiones de Claude Code (ociosa /
  trabajando / esperando aprobación / esperando entrada / compactando / terminada), vía *hooks* de Claude
  Code por una *named pipe* local. **Opt-in** desde Ajustes → Sesiones en vivo (con copia de seguridad y
  confirmación). El icono de bandeja añade un aviso ámbar cuando una sesión necesita tu atención.

### 📊 Señales de un vistazo + look nuevo
- **Marcador de ritmo** y **marcas de umbral** dentro de la propia barra de cuota.
- **Reset en hora local** ("se renueva en 1h 39m · mié 04:18") + explicación de la ventana móvil de 5h.
- Aviso de **datos desfasados** ("hace N min") y **sello de privacidad** honesto.
- **Icono de bandeja adaptativo** a la barra clara/oscura + **estado por forma** (accesible a daltónicos).
- **Sistema de diseño** coherente: rejilla de 8 pt, tipografía y dígitos tabulares, color de cuota
  interpolado por riesgo.
- **Panel de ajustes ⚙** dentro del dashboard: toda la configuración en un sitio; el menú derecho queda mínimo.

### 🩹 Arreglos
- El **sello de privacidad y el pie ya no se truncan**: se envuelven a varias líneas y el panel crece.
- Estabilidad del ciclo de pintado y del *layout* (medir/pintar consistente).

> Como siempre: el token solo se usa para leer **tu propia** cuota. No se almacena, registra ni envía a
> ningún otro sitio. Sin telemetría.
