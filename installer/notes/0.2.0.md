# ClaudeBar v0.2.0

**Novedad principal: actualizaciones automáticas.** A partir de esta versión ClaudeBar se actualiza
solo — comprueba al arrancar y te avisa, descarga e instala con un clic, verificando la firma.

### Nuevo
- 🔄 **Auto-actualización** con verificación de firma e instalador (sin reemplazar el .exe a mano).
- 📊 **Histórico de % real + pace/ETA**: ritmo de consumo y si vas a agotar la cuota antes del reset.
- 📈 **Gráfica de gasto por modelo** integrada en el dashboard (Opus/Sonnet/Haiku), ventana móvil 1h→30d.
- 🎨 **Temas** Oscuro / Claro / CLI + importación de paletas `.itermcolors`.
- 🌍 **9 idiomas** (sistema + en/es/nl/fr/de/ja/ko/zh-Hant).
- 🔔 **Notificaciones por hitos** (25/50/75/95 %) + alertas de ritmo proactivas.
- 🩺 **Estado del servicio** de Claude en el dashboard.
- 💾 **Caché offline**: muestra la última cuota conocida sin conexión o con rate-limit.

### Arreglos
- La etiqueta de "pico" ya no se solapa con el total/% en las gráficas.
- Varias mejoras de estabilidad del menú y el dashboard.
